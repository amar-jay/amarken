# Archive

`2026-08-23-pre-reset/` contains the training/evaluation system and generated
history removed from Amarken's active surface after repeated runs failed to
demonstrate capability above chance.

Nothing was deleted. Source, tests, configs, benchmarks, and documentation are
kept as ordinary archived files. Generated datasets, experiment reports,
tokenizer artifacts, and multi-gigabyte run directories remain local and are
ignored by Git; tracked predecessors remain recoverable from Git history.

The archive is intentionally inert. Paths inside archived configs and reports
are historical provenance and have not been rewritten to make the old system
look active.
